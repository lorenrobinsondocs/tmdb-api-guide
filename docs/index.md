# TMDB API Guide

A practical guide to The Movie Database API, written for developers making their first requests.

TMDB provides a free REST API for movie and TV data including titles, cast, images, ratings, and search. This guide focuses on getting started: authentication, making a working movie search request, understanding the response, and handling common errors and image URLs.

## Where to start

If you have never called the API before, begin with the [Quickstart](quickstart.md). It takes about five minutes and ends with a working search request.

If you already have a key and want more detail, the reference section covers error handling and working with TMDB image URLs.

## What this guide assumes

You can run commands in a terminal, and you have a free TMDB account. No prior API experience is needed. Examples are shown in curl, Python, and JavaScript.

## What this guide is not

This is not a replacement for TMDB's official reference. It is a working guide focused on the things that can trip developers up, the responses you actually get back, and how to read them.
